# База знаний музея «Двойное Дно»

Полная веб-база знаний для экскурсоводов.  
Содержит **полный текст всех разделов** из исходной «Книги знаний и ответов на вопросы музея «Двойное Дно»».

## Возможности

- Поиск по любому слову из всего текста книги
- Фильтры по основным разделам (Экскурсия, О деньгах, О людях, Термины, Приложения)
- Карточки с превью — **нажмите на карточку**, чтобы открыть полный текст раздела в удобном окне
- Желтоватый бумажный стиль «помятой книги»
- Данные в `data.js` — можно дополнять и обновлять

## Структура

```
museum-kb/
├── index.html
├── styles.css
├── data.js          ← полный текст всех разделов (169 карточек)
├── app.js
└── README.md
```

## Запуск

1. Откройте `index.html` в браузере.
2. Или разместите на GitHub Pages.

## Обновление данных

Редактируйте массив `knowledgeBase` в файле `data.js`.  
Каждый объект:

```js
{
  id: "уникальный-id",
  title: "Название раздела",
  category: "О людях",   // или другая категория
  content: "Полный текст раздела..."
}
```
